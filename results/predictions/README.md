# NeuroAction — Prediction Outputs & Data Dictionary

This directory contains trial-level and participant-level model prediction outputs generated during retrospective Leave-One-Subject-Out (LOSO) cross-validation.

---

## Prediction Files

### 1. `neural_goal_predictions_loso.csv`
Contains the out-of-fold neural goal classification predictions ($[-1000, 0]$ ms pre-movement EEG) across all 269 valid reach trials.

**Columns:**
- `participant_id`: Subject identifier (`sub-01`, `sub-02`, `sub-03`, `sub-08`, `sub-15`).
- `run_id`: Experimental run identifier (`run-01`, `run-02`).
- `trial_index`: Integer trial number within run ($0$–$39$).
- `trial_id`: Canonical unique trial key (e.g. `sub-01_run-01_L1_tr00`).
- `true_goal`: Ground truth instructed target direction (`left` or `right`).
- `predicted_goal`: Out-of-fold LDA decoded goal direction (`left` or `right`).
- `prob_left`: Posterior probability assigned to the left target $[0.0, 1.0]$.
- `prob_right`: Posterior probability assigned to the right target $[0.0, 1.0]$.
- `is_correct`: Binary accuracy flag ($1$ if `true_goal == predicted_goal`, else $0$).

### 2. `trajectory_endpoint_predictions_loso.csv`
Contains the 3D continuous reach endpoint predictions generated by the Ridge Kinematic Forecaster from a 200 ms prefix window (20 Leap Motion kinematic samples at 100 Hz).

**Columns:**
- `trial_id`: Canonical unique trial key.
- `participant_id`: Subject identifier.
- `actual_x_mm`, `actual_y_mm`, `actual_z_mm`: True physical hand endpoint coordinates (mm) at reach termination.
- `pred_x_mm`, `pred_y_mm`, `pred_z_mm`: Ridge model predicted endpoint coordinates (mm).
- `endpoint_error_mm`: 3D Euclidean distance between actual and predicted endpoints:
  $$\text{RMSE} = \sqrt{(x - \hat{x})^2 + (y - \hat{y})^2 + (z - \hat{z})^2}$$
- `prefix_duration_ms`: Duration of observed kinematic prefix ($200$ ms).
- `forecast_lead_time_ms`: Time in advance of physical reach completion ($t_{\text{end}} - 200$ ms, median $\sim 1000$ ms).

### 3. `reconciled_multimodal_evaluation_matrix.csv`
The reconciled master evaluation matrix produced during retrospective audit, joining neural decoder outputs, kinematic forecasts, and exploratory proxy target labels across all 269 valid trials.
